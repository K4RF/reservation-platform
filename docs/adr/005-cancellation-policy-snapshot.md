# ADR-005: 취소 정책을 예약 생성 시 값으로 복제해 Snapshot 저장

## 상태

Accepted

## 배경

숙소 관리자는 무료 취소 기준, 취소 마감일과 여러 부분 수수료 구간을 변경할 수
있습니다. 예약 후 숙소 정책이 바뀌더라도 이미 확정된 예약의 취소 조건과 금액
계산 결과는 달라지면 안 됩니다.

## 결정

- 숙소의 현재 정책은 `AccommodationCancellationPolicy`와 정렬된
  `CancellationFeeRule` 목록으로 관리합니다.
- 예약 생성 시 현재 숙소 정책의 기준일과 수수료 구간을 복사합니다.
- 기준일은 `reservations` 컬럼에, 가변 개수의 수수료 구간은
  `reservation_cancellation_fee_snapshots`에 저장합니다.
- 취소 계산은 숙소의 현재 정책을 다시 조회하지 않고 예약 Snapshot만 사용합니다.
- 일정 변경은 최초 예약 계약의 연속으로 보고 취소 정책 Snapshot을 교체하지
  않습니다.
- 숙소 정책이 등록되지 않은 경우 기존 전역 규칙인 `7일 무료`, `3일 이상 30%`,
  `1일 이상 50%`, `1일 미만 취소 불가`를 Snapshot으로 저장합니다.

## 대안

- 예약이 현재 숙소 정책을 직접 참조: 구현은 단순하지만 정책 수정이 과거 예약의
  취소 금액을 바꾸므로 요구사항을 만족하지 못합니다.
- 정책을 Versioning하고 예약이 버전을 참조: 중복 저장은 줄지만 현재 정책 선택,
  정책 삭제 금지, Version 수명주기 관리가 추가됩니다.
- Snapshot 전체를 JSON으로 저장: 구조 변경은 쉽지만 컬럼 제약, 조회 및 데이터
  검증이 어려워집니다.

## 결과와 한계

숙소 정책 변경과 무관하게 각 예약의 취소 조건을 재현할 수 있습니다. 반면 예약당
수수료 구간 행이 복제되어 저장 공간을 더 사용합니다. 현재는 취소 평가 결과 자체
또는 실제 결제·환불 결과를 저장하지 않으며, 이는 후속 Snapshot 및 결제 작업의
범위입니다.
